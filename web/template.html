Footnote

Every answer, with the exhibit that says so.

Footnote answers questions from a set of documents and shows its work. It stores the documents in Postgres, finds the passages most likely to hold the answer by meaning, and gives a small local model the top few to read. The model has to name the passage it used, or say "I don't know".

Answered by the Footnote server this page came from.

07Running it

Three containers

Postgres with pgvector, Ollama with the two models, and the Go API. The API serves this page with a live question box.

scripts/get-data.sh
docker compose up -d db ollama && docker compose run --rm models
docker compose run --rm ingest && docker compose up -d api
curl -s localhost:8080/ask -d '{"question": "Who ruled Normandy?"}'
